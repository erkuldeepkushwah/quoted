# 📄 Quoted

A lightweight and responsive **Quotation Maker** built using **HTML, CSS, and JavaScript**. It helps create professional quotations with live preview and printing support.

## 🚀 Live Demo

https://quotedbmaker.pages.dev/

## 📂 Repository

https://github.com/erkuldeepkushwah/quoted

---

## 📸 Preview

Create quotations quickly with a clean and user-friendly interface.

---

## ✨ Features

- ✅ Create Professional Quotations
- ✅ Client Information
- ✅ Add Work Details
- ✅ Automatic Total Calculation
- ✅ Live Preview
- ✅ Print Quotation
- ✅ Save as PDF
- ✅ Responsive Design
- ✅ Lightweight & Fast

## ▶️ Run Locally

Clone the repository

```bash
git clone https://github.com/erkuldeepkushwah/quoted.git
```

Go to the project folder

```bash
cd quoted
```

If using Node.js

```bash
npm install
npm start
```

Or simply open

```text
index.html
```

in your browser.
